# Console TPS - Unreal Engine 5 on PS4
<br>
This project is a PS4 Third Person Shooter named "This is my planet".

<br>
<br>

# Informations
<br>
The goal of this project was to start using consoles development kits with Unreal Engine 5. We used Unreal 5.4.4 and we had 4 weeks.

# Controls

## Keyboard

|    Key   |     Action    |
|     :---:     |     :---:     |
|    W / Z   |       Forward      |
|   S   |      Backward     |
|    A / Q   |       Move Left      |
|   D  |      Move Right     |
|   P / ESCAPE  |     Pause game     |
|    RIGHT MOUSE BUTTON   |       Aim OR Grab/Throw Animal            |
|    LEFT MOUSE BUTTON   |       Fire OR Grab/Throw Animal              |
|    MIDDLE MOUSE BUTTON   |       Switch between weapon and animals            |
|    SPACEBAR   |       Jump            |
|    LEFT SHIFT   |       Crouch            |

|    RIGHT TRIGGER   |       Aim OR Grab/Throw Animal            |
|    LEFT TRIGGER   |       Fire OR Grab/Throw Animal              |
|    LEFT/RIGHT SHOULDERS   |       Switch between weapon and animals            |
|    DOWN BUTTON   |       Jump            |
|    RIGHT JOYSTICK BUTTON   |       Crouch            |

# Features
<br>

Fight against a friend(?) to be the first to collect enough animals. To do so, you have to put them asleep with your gun, grab'em, and send'em back to HQ using our advanced Y.E.E.T platform technology. Should your colleague be more efficient than you, you could always throw some animals at them to hinder their progress.

- 2 players split-screen
- Jump, crouch, aim, grab and launch
- 5 animals with different behaviours and effects
